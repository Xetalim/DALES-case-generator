DALES Case Generator
====================

The ``moda`` package builds DALES cases from composable simulation modules.
Start with the end-to-end tutorial, then use a how-to guide for a specific task
or a concept page to understand how the generator assembles cases. The API
reference documents public objects; the developer catalog covers larger test
scenarios.
